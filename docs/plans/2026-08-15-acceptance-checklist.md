## A. 浏览器人工验收（Web UI）

### A1. 窄屏布局
- [ ] 移动端宽度（约 375px）下侧边栏收起为抽屉，汉堡按钮可展开
- [ ] 首页 / 今日任务 / 学习 / 测验 / 计划 / 成长 / 搭子 / 设置 各页无横向溢出、无错位

### A2. 刷新恢复
- [ ] 开始一个 Study Session，刷新页面后活动 Session 恢复（阶段、当前任务不丢）
- [ ] Session 完成后刷新，不再出现活动 Session，历史记录在 /growth

### A3. 批改响应中断后的重试
- [ ] 提交批改后立即刷新/断网，重试相同答案返回同一回执（score / correlationId 一致）
- [ ] 换答案重试返回 409 提示

### A4. 关闭桌宠模式
- [ ] 设置里切换到「关闭」，桌宠不再出现 / 干预
- [ ] 切换「安静」，不主动打扰

### A5. 开启访问 Token 后的完整 Web 流程
- [ ] 服务端设置 `STUDYMATE_ACCESS_TOKEN` 后，Web 首次访问弹出令牌输入门禁
- [ ] 输入正确 Token 后，建档 → 学习 → 测验 → 批改 → 搭子页面均可用
- [ ] 错误 Token 被拒，重新弹出输入
- [ ] 刷新页面 Token 仍在（sessionStorage），关闭标签页后失效

## B. 真实能力验收

### B1. 真实 LLM
- [ ] 配置 `OPENAI_API_KEY`，建档概念提取走真实模型（事件日志 model 非 `mock-llm`）
- [ ] 出题、批改、搭子对话走真实模型

### B2. 真实搜索
- [ ] 配置 `SERP_API_KEY`，建档调研返回真实来源（非 `search_disabled` 降级）

### B3. 一次完整建档闭环（真实搜索 + 真实 LLM）
- [ ] 创建考试 → 搜索调研 → 来源确认 → 构建知识 → 生成计划 → 计划确认 → 学习 Session → 出题 → 批改 → 复盘，全程无 mock 降级

- [ ] 第 3 天：连续打卡（streak=3）、SM-2 复习、错题回流
